## 4Ds of the Project

Hi all,

It is important to see your project as a dynamic, holistic system with 4Ds:

_WHAT do you solve and WHY?_
Define: fully identify and very clearly state the problem you want to work on;  goals and requirements, specifications; success criteria of the "done";

_Blueprint phase showing HOW?_
Design: sketches, more detailed plans, diagrams, architecture diagrams, usage flows. System architecture design, data model and database design, technology stack selection, prototyping;

_First part of the implementation phase_
Develop: code, build, unit integration, API integration; debugging, unit testing, integration testing, system testing; turn designed solutions into a working product;

_Launch and maintain; user validation_
Deploy: release, test, and monitor the final product in its target environment for end-users. Deployment by steps, environment setup, data migration, UAT, go-live, post-deployment monitoring, maintenance and support, documentation;
